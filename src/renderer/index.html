MultiRP Quick Start

  1. Open the Discord Developer Portal and create an Application per profile.
  2. Copy the Application (Client) ID into the profile field.
  3. (Optional) Upload images under Rich Presence → Art Assets, then use the asset name as the Image Key.
  4. Fill Details and State, add up to 2 buttons.
  5. Click Activate. Discord must be open on your computer.

Buttons are clickable for other users only — that is a Discord limit, not a bug.

✨ Drop-in CustomRP compatibility. Inspired by CustomRP (customrp.xyz) — your existing .crp presets import and export here, no conversion needed. MultiRP also reads & writes .json, .csv, .md, and .txt, so you can move presets between any tool that speaks plain text.
